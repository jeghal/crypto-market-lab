# مشاريع Binance

مساحة عمل تحتوي ثلاثة مشاريع فقط: trading-dashboard وATLASFLOW وdata_pipeline، مع الحفاظ على استقلال واجهاتها وطريقة تشغيلها.

## البداية

المتطلبات: Node.js 22 أو أحدث وPython 3.10 أو أحدث. جرى التحقق محلياً باستخدام Node 24 وPython 3.14.

```powershell
npm start
```

افتح <http://127.0.0.1:8000/> لاختيار المشروع. لا يحتاج تشغيل الصفحات إلى تثبيت مكتبات JavaScript؛ مكتبة ZIP المستخدمة موجودة محلياً.

## المشاريع

| المجلد | الغرض |
| --- | --- |
| trading-dashboard | متابعة السوق والتحليل وحاسبة الصفقة  |
| ATLASFLOW | مساعد تعليمي وتحليل بصري مستقل |
| data_pipeline | إنشاء حزمة بيانات للتحليل |

يمكن تشغيل مشروع واحد من مجلده عبر `python -m http.server 8000`. روابط الانتقال إلى المشاريع الأخرى تفترض تشغيل الخادم من مجلد مساحة العمل.

## التطوير والتحقق

```powershell
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
npm test
npm run test:ui
npm run test:workspace-ui
npm run test:bundles
```

`npm run test:live` يفحص وقت Binance وقواعد الزوج والشموع وbookTicker والبث الحي بقراءة البيانات العامة فقط. لا يستخدم مفاتيح حساب ولا ينفذ صفقات. يُحفظ التقرير في `_Reports/live-check.json`.

اختبارات المنطق والواجهات والحزم الأخرى تستخدم بيانات محاكاة. اختبارات الواجهة مع الشبكة الحية اختيارية عبر `LIVE_BINANCE=1`؛ تبقى نتائجها متأثرة بحالة الشبكة والسوق.

## تعديل المصدر المشترك

عدّل `shared/market-core.js` أو `shared/pipeline/`، ثم شغّل:

```powershell
npm run build
npm test
```

الملفات ذات ترويسة GENERATED نواتج توزيع محلية؛ لا تُعدّل مباشرة. يحتفظ كل مشروع بنسخته المولدة ليظل قابلاً للتشغيل والنقل منفرداً. يتحقق الاختبار من تزامنها.

## حالة البيانات

توضح لوحة التداول عمر بيانات التحليل والفريم الفعلي وحالة البث. عند انقطاع الاتصال أو فشل تحديث التحليل يظهر تنبيه قدم البيانات.

التفاصيل والافتراضات في [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)، وتنظيم المجلد في [README_ORGANISATION.md](README_ORGANISATION.md).

## حفظ الإصدارات

المجلد مستودع Git محلي. بعد التعديل والتحقق، راجع `git diff` ثم أنشئ commit. الأرشيفات والأسرار والبيئات والتقارير المولدة مستبعدة عبر `.gitignore`. لا يوجد رفع تلقائي إلى مستودع بعيد.
