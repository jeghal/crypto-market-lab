# حدود المشاريع

تطورت المشاريع بصورة مستقلة، ويحتفظ كل واحد منها بغرضه وطريقة تشغيله:

| المشروع | المسؤولية |
| --- | --- |
| trading-dashboard | متابعة السوق والتحليل وسجل الإشارات |
| ATLASFLOW | مساعد تعليمي وتحليل بصري مستقل |
| data_pipeline | تصدير حزمة بيانات سوق مستقلة |
| formation | المحتوى التعليمي |
| tools | أدوات مستقلة للتجريب والمراجعة |

صفحة الجذر تجمع روابطها. لا تنقل البيانات الخاصة أو تحول أي مشروع إلى جزء إلزامي من واجهة مشروع آخر.

## المصدر المشترك

`shared/market-core.js` هو المصدر المعتمد للاتصال العام، والمهل، والإلغاء وإعادة المحاولة، والتقريب وEMA وATR. يحافظ EMA على إعداد تهيئة مختلف عند الحاجة: SMA في لوحة التداول، وأول قيمة في ATLASFLOW؛ لا تتغير معايرة المؤشر ضمن عملية التنظيم.

`shared/pipeline/` هو المصدر المعتمد لواجهات Binance والمجمّعات والتحويلات المشتركة بين Data Pipeline والرادار المدمج. إعداد حدود الشموع مختلف لكل واجهة. وظائف الرادار الإضافية محفوظة، ويحتوي manifest على حقلي version وbundle_generator_version للتوافق.

ينسخ `node scripts/sync_shared.mjs` هذه المصادر إلى مجلدات المشاريع مع ترويسة GENERATED. هذا مقصود حتى يمكن نشر أو نقل كل مشروع منفرداً وتشغيله دون مجلد أب. لا تعدّل الملفات المولدة يدوياً؛ يفشل `npm test` إذا اختلفت عن المصدر.

## سجل الإشارات

يُسجّل قرار الشراء المؤكد مرة واحدة لكل زوج/إعداد تحليل/شمعة 15 دقيقة عند ظهوره، مع الوقت والمستويات والتكاليف المفترضة. يظل السجل محلياً في المتصفح، بحد أقصى 500 إشارة. التصدير مطلوب للحفظ الطويل أو المقارنة بين الأجهزة.

التقييم متابعة مستقبلية: دخول افتتاح أول شمعة كاملة بعد رصد الإشارة، وأفق 192 شمعة من 15 دقيقة. لا تُستنتج حركة داخل الشمعة. لمس الهدف والوقف معاً نتيجة غير محسومة، وفجوات التاريخ تبقي السجل معلقاً. لا يحسب معدل النجاح قبل اكتمال النتائج، ويظهر تنبيه للعينة الصغيرة. جمع 30 نتيجة حد عرض مبدئي وليس إثباتاً إحصائياً للربحية.

## التحقق

`npm test`: تزامن المصادر، اختبارات المنطق والانحدار والسجل، وفحص precache.

`npm run test:ui`: فحوص لوحة التداول ببيانات محاكاة.

`npm run test:workspace-ui`: تنقل المشاريع، قدم البيانات وفشل الشبكة والاسترجاع وصفحة السجل.

`npm run test:live`: طلبات عامة قليلة وحقيقية من Binance؛ لا يستخدم مفاتيح ولا يستدعي نقاط تنفيذ الأوامر. يحفظ التقرير في `_Reports/` ويبين فشل الشبكة بوضوح.
